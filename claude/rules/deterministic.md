# Deterministic

The owner's pillar (2026-10-29): **always pursue the deterministic.** A first version may be an agent following a rule; it then evolves into a script, hook, test or check that does the same every time, with AI kept only where judgement is needed. Before building, look for a ready open-source solution. When a rule depends on an agent remembering it, propose the hook or check that enforces it (e.g. `claude-guard-main-clone`).
