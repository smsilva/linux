# Language

- Talk to the owner in pt-BR (chat replies)
- Everything else in English: files and their names, H1 titles (matching the filename), artifacts, Agent Skills, source code, comments, shell scripts (help text and log messages included), commit messages, PR descriptions
- One exception: in an existing project whose docs are in another language, keep editing those docs in that language; new files, scripts and code stay in English
- Never translate technical terms (API, endpoint, commit, push, pull request, cache, parse)
