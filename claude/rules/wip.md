# Work in progress

The owner's pillar for every project (2026-10-29; raised from 1 to 3 the same day, then to 10 on 2026-10-30 because the work runs through subagents): **at most ten issues In Progress at a time**, per person, on every board.

- With ten items In Progress, finish one, or give it back (to `Todo`, with a handoff comment), before taking another one.
- A parent whose sub-issues are the work goes In Progress too, when its first sub-issue is claimed (owner, 2026-11-05), so the board shows the initiative under way. It does not count toward the ten: the sub-issues being worked on are the work.
- When a board shows more than ten items In Progress for the same person, say so and ask which ones stay; release the others before starting.
- The board's own script enforces it where one exists (Nereus: `scripts/board/queue claim` refuses an eleventh item, nereus#615), as the deterministic pillar asks.
