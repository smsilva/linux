# OBS Studio

`config/` is a versioned snapshot of `~/.config/obs-studio` (profile and scene collection `Untitled`).

## Excluded

| Item | Reason |
|------|--------|
| `plugin_config/obs-websocket/config.json` | holds the WebSocket server password |
| `global.ini` → `InstallGUID` | unique installation identifier |
| `basic.ini` → `[Panels] CookieId` | browser dock cookie storage identifier |
| `logs/`, `profiler_data/`, `*.bak` | runtime output |
| `plugin_config/rtmp-services/`, `updates/`, `plugin_manager/` | caches downloaded or regenerated by OBS |

A stream key, if one is ever configured, lands in `basic/profiles/<name>/service.json`: never copy that file here.

## Restore

With OBS closed:

```bash
cp --recursive --no-target-directory apps/obs-studio/config ~/.config/obs-studio
```

OBS regenerates the excluded files on the next start.

## Update the snapshot

```bash
grep --invert-match '^InstallGUID=' ~/.config/obs-studio/global.ini > apps/obs-studio/config/global.ini
cp ~/.config/obs-studio/user.ini apps/obs-studio/config/user.ini
grep --invert-match '^CookieId=' ~/.config/obs-studio/basic/profiles/Untitled/basic.ini \
  | sed --expression '/^\[Panels\]$/,/^$/d' \
  > apps/obs-studio/config/basic/profiles/Untitled/basic.ini
cp ~/.config/obs-studio/basic/scenes/Untitled.json apps/obs-studio/config/basic/scenes/Untitled.json
```
