# Agent names

The owner's rule for every repository (2026-10-31): **every agent session on this machine has a unique name from the NATO phonetic alphabet**, lowercase, in the ICAO spelling: alfa, bravo, charlie, delta, echo, foxtrot, golf, hotel, india, juliett, kilo, lima, mike, november, oscar, papa, quebec, romeo, sierra, tango, uniform, victor, whiskey, x-ray, yankee, zulu.

- **The names go round, like hurricane names (2026-11-03):** each session takes the next name after the last one given; the list starts over only after zulu, skipping the names still in use. With all 26 in use at once: `alfa-2`, `bravo-2` and so on.
- **The reference:** the Atlantic hurricane names, kept by a World Meteorological Organization (WMO) committee: six lists of 21 names, one per year, recycled every six years; each storm takes the next name, and a season that runs out of names goes on in a supplemental list (the [National Hurricane Center's page](https://www.nhc.noaa.gov/aboutnames.shtml), the [WMO's 2021 decision](https://public.wmo.int/node/20645)). Taken from it: the next name in order, and a second list when the first runs out (the suffix here). Not taken: one list here instead of six, it starts over when it ends instead of each year, and no name is ever retired.
- **The hooks give it, not the agent:** `SessionStart` runs `nato-name hook`, which takes the next free name (atomically, under `flock`, in `~/.local/state/nato-names/`, one file per name, `.last` for the last one given) and puts "Your name is <name>" in the session's context; `SessionEnd` frees it. A freed name, or one whose process is gone (a crash, a kill), comes back on its turn. `/clear` keeps the name.
- **The launcher shows it:** `agent` reserves the name before Claude Code starts and passes it as `--name`, so other sessions see it in `ListAgents` and the owner sees it in the session list. It also names the tmux window after the session, unless the window was named by hand, and gives the window back to tmux's own name when the session ends. It turns on Remote Control under that name by default (`--local`, `-L`, leaves it off, and so does `AGENT_REMOTE=false` in the environment); `claude-remote-session` does the same in a new window.
- **Know it and say it:** when the owner asks your name, answer with it. Sign cross-session messages, orders and replies with it when relevant. A subagent has no name of its own: it works under its session's.
- **Look it up:** `nato-name whoami --session-id <id>`; `nato-name list` shows every name in use, its session, pid and whether it is still alive.
- A repository's own naming rule for sessions (a tmux window name) gives way to this one.
