# Language

- Talk to the owner in pt-BR (chat replies)
- Generate everything else in English: files, artifacts, source code, comments, commit messages, PR descriptions
- Write Agent Skills in English
- Write shell/bash scripts in English: comments, `show_usage`/help text, and log/error messages — even in a project whose docs (`CLAUDE.md`, `HANDOFF.md`, `.md` body text) are in another language
- Never translate technical terms (API, endpoint, commit, push, pull request, cache, parse)
- Name documentation files in English (`00-account-strategy.md`, not `00-estrategia-de-contas.md`) — applies to new files and to renaming existing ones
- Write the H1 title in English too, so it matches the filename. In an existing project whose docs are in another language, keep editing those docs in that language
- Don't repeat the parent folder name in the filename (`dns/05-security.md`, not `dns/05-dns-security.md`) — see architecture.md
