# Work in progress

The owner's pillar for every project (2026-10-29): **one issue In Progress at a time**, per person, on every board.

- Finish the item In Progress, or give it back (to `Todo`, with a handoff comment), before taking another one. There is no "new item while one is open".
- A parent whose sub-issues are the work stays out of In Progress; only the sub-issue being worked on is In Progress.
- When a board shows more than one item In Progress for the same person, say so and ask which one stays; release the others before starting.
- The board's own script enforces it where one exists (Nereus: `scripts/board/queue claim` refuses a second item), as the deterministic pillar asks.
